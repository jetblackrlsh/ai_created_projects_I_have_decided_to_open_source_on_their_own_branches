# Prior-work lessons

Sunlit Spires was an image-derived reconstruction: hundreds of thousands of traced palette contours preserved reference pose and architecture but were not semantic character parts. Such geometry is unsuitable as an original-art basis or an articulated rig without remodeling. Pixel metrics described reconstruction error, not art quality.

Keeper of the Dawn Atlas was newly authored graphic illustration: named groups, Canvas Path2D primitives, gradients and separate character/environment parts. Its bloom pipeline used actual highlight extraction, horizontal and vertical Gaussian blur, then final GLSL composition. The stylized result did not equal the reference's painterly modeling or texture density. Increasing path count cannot establish that equivalence.

Both workflows demonstrated that Canvas and GLSL can execute under native Canvas plus Mesa when a sandbox blocks Chromium sockets. Report that narrow evidence accurately: shader compile/link/render and pixel response can be verified without proving browser buttons, download behavior or UI responsiveness. Never label a headless framebuffer image a browser screenshot.

Use these technical lessons without hard-coding previous characters, compositions, machines, filesystem locations or output sizes into new work.
