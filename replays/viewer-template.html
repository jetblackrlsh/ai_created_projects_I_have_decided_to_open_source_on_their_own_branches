    Reconstruction & visibility notes

    Complete inputs are required. Unsupported, truncated or ambiguous logs are rejected rather than guessed. A / Player is the viewing perspective; opponent hand identities and face-down cards stay concealed until their public events. Imported data is never executed.

    Replay Viewer v1.1 • Original Aether Snap engine preserved • Event-based playback, configurable speed • Keyboard: Space play/pause, ←/→ step, Home reset

    Reliable MP4 export

    For a real H.264 MP4, download the v1.1 toolkit ZIP and use its local Node export command. Browser video codecs vary; this viewer never renames WebM as MP4.

    1. Click Save replay bundle below.
    2. Extract the toolkit ZIP; install Node.js ≥18, ffmpeg with libx264, and run npm install @napi-rs/canvas in that folder.
    3. Run:
      node export-replay.cjs mp4 replay.json match.mp4

    Default: full original event timeline, 1920×1080, H.264, yuv420p, 30 fps. Add --speed 2 for 2× pacing. PNG exports work directly in this HTML without Node.
