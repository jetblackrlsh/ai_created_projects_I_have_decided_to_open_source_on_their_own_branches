# Provenance

This release combines the two requested AI-assisted agent workflows, create-spread-motion-comic and create-eight-page-comic-spreads, with the local audio setup/adapters needed to make the former usable without private skills. Source contributions were developed for Jet Black and adapted into a generic public package with private delivery instructions and private character-canon dependencies removed. The public renderer additionally caches identical hold frames; its changing-aspect overview zoom remains contained and letterboxed.

The included audio setup, Kokoro and Stable Audio adapters, priority mix and sound-effect comfort code originate in the same AI-assisted visual-novel tooling. Filenames retain their original `vn` names to make this origin clear. Their runtime/schema guidance is bundled, but unrelated visual-novel renderers, private story fixtures, historical reports and personal skill identifiers are excluded.

No third-party runtime source, pretrained weights, personal images, fonts or copyrighted sample stories are included. External model files are pinned by official URLs, revision, size and SHA-256 in the runtime manifest. External packages and model distributions retain their own licenses; see THIRD_PARTY_NOTICES.md. This project's CC0 dedication cannot grant rights the contributors do not hold.

The original private comic and its audio/video are intentionally not release fixtures. All new release tests use synthetic source pixels and audio. The release does not claim that a fresh full model restore, image generation, speech inference or human listening was repeated during packaging.
