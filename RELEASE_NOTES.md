# 1.0.0 — The Unbound Accord

- Seven original adult fairy custodians and a new multiverse setting.
- A seven-chapter campaign about restoring passage, memory, time, consent,
  possibility, identity, and freedom.
- 56 cards with base and attuned versions; seven passives and ultimates.
- Original local illustrations in a vivid modern-anime, prismatic fantasy style.
- Solo/cooperative story play and configurable versus battles.
- Original local save namespace and readable LUMEN chapter codes.
- Plain browser runtime without services, accounts, telemetry, or API keys.
- Reproducible development regression checks and separated code/art licenses.

## Known limits

The release includes deterministic DOM/logic tests, not certification of every
browser, screen reader, device, or audio system. Generated art can contain minor
anatomical or continuity imperfections. Use the browser's zoom controls if card
text is small. Local browser storage is not a cloud backup.

Level codes are convenience game-state strings, not secure credentials. This
is a local game, not an authoritative multiplayer service or anti-cheat system.
