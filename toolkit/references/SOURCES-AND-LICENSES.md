Runtime: Python standard library (install Python separately). Optional/export executable: Inkscape, installed separately under its own license (https://inkscape.org/about/license/). Test dependency: Pillow, installed separately under its own license (https://python-pillow.github.io/pillow-perf/ links to project; authoritative license https://github.com/python-pillow/Pillow/blob/main/LICENSE). Fonts are resolved from the local machine and are not redistributed. SVG output is available without Inkscape through heroic.render().
